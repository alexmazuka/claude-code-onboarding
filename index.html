Как работать в Claude в режиме «Код»

Короткая инструкция для нового участника команды: что такое вкладка Code, чем она лучше обычного чата и как за 10 минут сделать первую задачу.

Чат и Код: в чём разница

Обычный чат (Chat)

Отвечает текстом. Файлы надо загружать вручную, результат копировать к себе. Хорош для вопросов и черновиков.

Режим Code

Claude сам работает в папке на вашем компьютере: читает и создаёт файлы, запускает команды, открывает сайты во встроенном браузере, ведёт план задачи и показывает результат.

Шаг 1

Откройте вкладку Code и выберите папку

  1. Откройте приложение Claude для Mac или Windows и войдите в командный аккаунт.
  2. Вверху переключитесь с Chat на Code 1.
  3. Нажмите New session 2 и выберите рабочую папку проекта 3, например Desktop/operations.

Без папки сессия работает во временной папке и удаляется вместе с сессией. Для постоянной работы всегда выбирайте папку проекта.

Шаг 2

Поставьте задачу обычными словами

Пишите как коллеге: что нужно, откуда взять данные, в каком виде результат. Claude составит план 4 и будет показывать каждое действие 5.

Шаг 3

Подтверждайте действия

Перед изменением файлов, отправкой писем или публикацией Claude спрашивает разрешение. Внизу поля ввода можно выбрать режим разрешений:

  • Ask — спрашивает каждый раз. Начинайте с него.
  • Auto — безопасные действия выполняет сам, рискованные всё равно спрашивает.
  • Plan — сначала только план, без изменений, пока вы его не одобрите.
Шаг 4

Забирайте результат

Готовые файлы появляются в выбранной папке и открываются кликом прямо из чата. Страницы и отчёты Claude может опубликовать как приватный артефакт со ссылкой, которой можно поделиться с командой.

Преимущества премиум-аккаунта в Code

Работа с вашими файлами

Excel, Word, PDF, видео, папки целиком. Не нужно загружать и скачивать вручную.

Сильнейшие модели

Доступ к Opus для сложных задач и большие лимиты использования.

Навыки команды

Готовые сценарии через /: дайджест прессы, мониторинг персон, наративы, монтаж видео.

Подключённые сервисы

Почта, календарь, Notion, Slack, Google Drive, Jira — Claude читает и готовит черновики.

Встроенный браузер

Сам открывает сайты, собирает информацию, проверяет страницы.

Параллельные сессии и расписание

Несколько задач одновременно и регулярные задачи по расписанию, например утренний дайджест.

Какую модель выбрать

Модель переключается в поле ввода внизу (чип с названием модели).

Opus

Самая умная, быстрее всех расходует лимит. Для сложного анализа, длинных отчётов и многошаговых задач.

Sonnet

Баланс качества и скорости, экономнее Opus. Для большинства повседневных задач.

Haiku

Самая быстрая и экономная. Для простого: переформулировать, разобрать список, короткая сводка.

Правило: начинайте с Sonnet и переключайтесь на Opus, если ответ недостаточно глубокий.

Как следить за лимитами

  • В приложении или на claude.ai откройте Settings → Usage: там видно, сколько использовано и когда лимит сбросится.
  • Когда лимит подходит к концу, приложение само предупреждает.
  • В терминальной версии claude есть команда /usage.
  • Opus тратит лимит быстрее всех, для рутинных задач берите Sonnet.

Рутины: задачи по расписанию

  1. Во вкладке Code напишите словами, например: «каждый будний день в 8:00 делай дайджест западной прессы и присылай ссылку».
  2. Claude создаст задачу по расписанию. То же можно сделать напрямую командой /schedule.
  3. Посмотреть, изменить или удалить рутину: попросите Claude или вызовите /schedule.
  4. Чтобы повторять задачу внутри открытой сессии, есть /loop, например /loop 30m проверь почту.

Ставьте в рутину готовый навык (дайджест, мониторинг персоны), тогда результат каждый раз будет в одном формате.

Полезные команды

Команды вводятся в поле сообщения и начинаются с /. Наберите /, чтобы увидеть полный список.

/compact — сжать контекст

Длинная сессия забивает память модели, ответы становятся медленнее, лимит тратится быстрее. Команда сворачивает историю в краткую сводку и продолжает работу. Можно уточнить, что сохранить: /compact оставь только решения по отчёту. При переполнении Claude сжимает контекст и сам.

/clear — начать с чистого листа

Полностью очищает историю сессии. Используйте, когда переходите к другой задаче. Удобнее просто открыть новую сессию.

/usage — лимиты

Сколько лимита израсходовано и когда он сбросится.

/schedule и /loop

Задачи по расписанию и повтор задачи в открытой сессии, подробнее в разделе о рутинах.

/init — память о проекте

Создаёт в папке файл CLAUDE.md с описанием проекта. Claude читает его в начале каждой сессии, и не нужно объяснять одно и то же заново.

/имя-навыка

Запускает навык напрямую, например /narratives или /person-monitor.

Навыки и коннекторы

Навыки (skills)

Готовая инструкция для повторяющейся задачи: шаги, источники, формат результата. Навык делает так, что дайджест или отчёт каждый раз выходит одинаковым по структуре и качеству.

Как пользоваться: напишите задачу словами («сделай наративы за сегодня»), и Claude сам подберёт навык, или вызовите его через /. Новый навык можно создать, попросив: «сделай из этого навык».

Коннекторы

Подключения к внешним сервисам: почта, календарь, Google Drive, Notion, Slack, Jira и другие. Через них Claude читает данные и готовит черновики прямо в этих сервисах.

Подключаются в Settings → Connectors, вход в сервис делаете вы сами. Письма, публикации и другие действия наружу Claude выполняет только после вашего подтверждения.

Правила команды

  • Одна задача — одна сессия. Называйте сессии понятно.
  • Не вводите пароли и данные карт в чат — Claude их и не попросит.
  • Проверяйте факты и цифры перед отправкой наружу.
  • Если не уверены, начните с режима Plan.
  • Вопросы по работе Claude можно задать самому Claude: «как сделать в Claude Code…?»
